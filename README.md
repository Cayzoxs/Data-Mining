# Praktikum Data Mining

Repository ini digunakan untuk mendokumentasikan praktikum mandiri mingguan mata kuliah **Data Mining** pada Program Studi Teknik Informatika.

## Tujuan
- Mempraktikkan konsep dan algoritma Data Mining menggunakan Python.
- Mendokumentasikan proses, kode, hasil, dan interpretasi setiap praktikum.
- Menyimpan latihan secara terstruktur agar mudah ditinjau kembali.

## Lingkup Materi
Folder disusun berdasarkan topik pada materi pengantar perkuliahan. Urutan dan isi dapat disesuaikan dengan tugas atau instruksi dosen setiap minggu.

| Folder | Topik rencana |
|---|---|
| `Minggu-01-Pengantar-Data-Mining` | Konsep dasar Data Mining dan CRISP-DM |
| `Minggu-02-Jenis-Data` | Jenis data, atribut, dan pengukuran |
| `Minggu-03-Preprocessing` | Data cleaning, missing values, transformasi data |
| `Minggu-04-Metode-Learning` | Supervised, unsupervised, dan peran Data Mining |
| `Minggu-05-Naive-Bayes` | Klasifikasi Naive Bayes |
| `Minggu-06-KNN` | Klasifikasi K-Nearest Neighbors |
| `Minggu-07-Decision-Tree` | Klasifikasi Decision Tree |
| `Minggu-08-ANN-Deep-Learning` | Pengenalan ANN dan implementasi dasar |
| `Minggu-09-Konsep-Clustering` | Konsep dan jenis clustering |
| `Minggu-10-K-Means` | Clustering dengan K-Means |
| `Minggu-11-Hierarchical-Clustering` | Agglomerative Hierarchical Clustering |
| `Minggu-12-Regresi` | Regresi sederhana dan multivariat |
| `Minggu-13-Association-Rule` | Apriori atau FP-Growth |
| `Minggu-14-Evaluasi-Model` | Validasi dan evaluasi model |

> Catatan: folder di atas adalah kerangka awal berdasarkan materi pengantar. Tidak semua topik harus dikerjakan pada minggu tersebut; ikuti instruksi aktual dosen.

## Struktur Folder Praktikum

Setiap folder mingguan dapat berisi:
- `README.md` — tujuan, dataset, langkah, hasil, dan kesimpulan.
- `praktikum.ipynb` — notebook Python.
- `data/` — data kecil yang boleh didistribusikan, jika diperlukan.
- `outputs/` — visualisasi atau tabel hasil.

## Tools
- Python
- Jupyter Notebook / Google Colab
- pandas, NumPy, Matplotlib, Seaborn
- scikit-learn
- mlxtend (jika dibutuhkan untuk association rule)

## Cara Menggunakan
1. Buka notebook di Google Colab atau Jupyter Notebook.
2. Baca instruksi pada `README.md` folder terkait.
3. Jalankan kode secara berurutan.
4. Tambahkan interpretasi hasil dengan bahasa sendiri.
5. Simpan output atau screenshot penting jika diminta dosen.

## Prinsip Dokumentasi
Setiap praktikum sebaiknya menjelaskan **apa yang dilakukan, mengapa metode dipilih, hasil yang diperoleh, dan apa arti hasil tersebut**. Jangan hanya menyertakan kode tanpa interpretasi.
