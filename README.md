# Praktikum Data Mining

Repository ini berisi dokumentasi dan pengerjaan praktikum mingguan mata kuliah **Data Mining** menggunakan Python. Materi disusun mengikuti topik perkuliahan dan akan dilengkapi secara bertahap sesuai pelaksanaan praktikum.

## Tujuan Repository

- Mendokumentasikan proses belajar dan pengerjaan praktikum Data Mining.
- Mempraktikkan pengolahan dan analisis data menggunakan Python.
- Menerapkan metode Data Mining sesuai materi perkuliahan.
- Menyimpan notebook, hasil analisis, visualisasi, dan kesimpulan praktikum secara terstruktur.

## Teknologi yang Digunakan

- Python
- Jupyter Notebook atau Google Colab
- Pandas dan pustaka Python lain sesuai kebutuhan praktikum
- Git dan GitHub untuk pengelolaan versi

## Struktur Repository

Setiap praktikum mingguan dikerjakan pada branch tersendiri. Branch `main` digunakan untuk menyimpan informasi umum repository, sedangkan branch praktikum menyimpan file dan hasil pengerjaan untuk minggu terkait.

Contoh nama branch:

- `praktikum/minggu-01`
- `praktikum/minggu-02`
- `praktikum/minggu-03`

Di dalam branch praktikum, file akan ditata dalam folder sesuai minggu dan topik. Umumnya folder praktikum berisi:

- `README.md` — tujuan, langkah kerja, hasil, dan kesimpulan praktikum.
- `praktikum.ipynb` — notebook berisi kode, analisis, dan hasil pengerjaan.

File tambahan seperti dataset atau visualisasi disertakan bila diperlukan.

## Cara Menjalankan Notebook

1. Buka notebook (`.ipynb`) pada branch praktikum yang sesuai.
2. Jalankan menggunakan Google Colab atau Jupyter Notebook.
3. Jalankan sel kode secara berurutan dan periksa hasilnya.
4. Lengkapi analisis dan kesimpulan berdasarkan hasil yang benar-benar diperoleh.
